# Diagramme de cas d'utilisation

## 1. Objectif

Le diagramme de cas d'utilisation présente les interactions entre les utilisateurs et la plateforme EduAdvice.

Il permet de représenter les principales fonctionnalités accessibles aux utilisateurs dans le périmètre du MVP.

## 2. Acteur

- **Utilisateur :** personne qui consulte les informations
  proposées par la plateforme EduAdvice.

## 3. Cas d'utilisation

Les principaux cas d'utilisation correspondent aux fonctionnalités définies dans le périmètre du MVP :

| Identifiant | Cas d'utilisation | Description |
|---|---|---|
| UC-01 | Consulter la présentation d'une formation | Accéder aux informations générales d'une formation. |
| UC-02 | Consulter le programme | Parcourir le programme organisé par semestre. |
| UC-03 | Consulter une fiche matière | Accéder aux informations relatives à une matière. |
| UC-04 | Consulter les ressources pédagogiques | Accéder aux ressources externes associées aux matières. |
| UC-05 | Consulter les débouchés professionnels | Découvrir les métiers et secteurs associés à une formation. |
| UC-06 | Naviguer sur la plateforme | Accéder aux différentes rubriques et revenir aux pages précédentes. |
