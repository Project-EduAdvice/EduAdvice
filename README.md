# EduAdvice

**Plateforme web de centralisation des informations sur les formations universitaires.**

## Présentation

EduAdvice est un projet universitaire visant à centraliser et organiser
les informations relatives aux formations universitaires afin de faciliter
leur consultation par les étudiants et les futurs candidats.

## Objectifs

- Présenter les formations et leurs parcours.
- Organiser les programmes par niveau et semestre.
- Consulter les unités d'enseignement et les matières.
- Accéder à des ressources pédagogiques externes.
- Découvrir les débouchés professionnels et les compétences associées.

## Périmètre initial

Le premier périmètre couvre le Master Informatique de l'Université
Sorbonne Paris Nord :

- Programmation, Sûreté et Sécurité (P2S).
- Exploration informatique des données et décisionnel (EID²).

## Technologies

- Backend : Java / Spring Boot
- Frontend : React
- Base de données : PostgreSQL

## Organisation du dépôt

- `backend/` : application serveur.
- `frontend/` : application cliente.
- `docs/` : documentation fonctionnelle et technique.
- `.github/` : modèles de contributions et de tickets.
